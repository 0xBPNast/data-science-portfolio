## Projects

- **[gearbox-fault-cnn](projects/gearbox-fault-cnn/)** — End-to-end framework for gearbox fault classification, combining a physics-based 8-DOF lumped-parameter dynamic model for synthetic data generation with a 1D-CNN trained across time, frequency, angular, and order signal domains. *(BEng Hons thesis, University of Pretoria, 2024.)*
- **[condition-monitoring](projects/condition-monitoring/)** — Custom Python implementations of classical and learning-based diagnostic techniques for gearboxes and bearings: TSA, Spectral Kurtosis, Envelope Analysis, Bayesian Geometry Compensation, Computed Order Tracking, and PCA-based Health Indicators.
